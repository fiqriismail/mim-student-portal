# FE-1.1 Self-Registration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the registration screen (US-1.1's frontend half): a `/register` form (name, email, phone, password, confirm password, T&C checkbox, Cloudflare Turnstile challenge), a `POST /api/register` Next.js Route Handler that verifies the Turnstile token and forwards to BE-1.1's `POST /identity/register` (already merged on `main`), and a `/register/check-email` confirmation page.

**Architecture:** The Route Handler is the BFF proxy (`ARCHITECTURE.md` §6.1) — the browser never calls the ASP.NET API directly. Turnstile verification happens server-side inside the Route Handler; the secret key never reaches the browser. The form is a Client Component using `react-hook-form` + `zod` for client-side validation (the shadcn-documented pattern); the check-email page is a Server Component reading a query param.

**Tech Stack:** Next.js 16 (App Router), TypeScript, `react-hook-form`, `zod`, `@hookform/resolvers`, `@marsidev/react-turnstile`, shadcn/ui (`form`, `input`, `checkbox`, `label`), Vitest + React Testing Library (unit/component tests), Playwright (one happy-path smoke test).

**Spec:** [`docs/superpowers/specs/2026-08-21-fe-1.1-self-registration-design.md`](../specs/2026-08-21-fe-1.1-self-registration-design.md)

## Global Constraints

- Password minimum length: 10 characters, no complexity rule beyond length (AC-1.1.3) — mirrors BE-1.1's `RegisterValidator`.
- Password/confirmation mismatch: error attaches to the confirmation field only, neither field is cleared (AC-1.1.4) — `react-hook-form` preserves values by default; do not add code that resets the form on validation failure.
- T&C checkbox must be `true` to submit (AC-1.1.5); links open in a new tab (`target="_blank" rel="noopener noreferrer"`).
- Turnstile challenge blocks submission until a token is present (AC-1.1.10) — implemented by keeping the submit button `disabled` until the widget's `onSuccess` callback fires, not by a separate error message.
- On success, redirect to `/register/check-email?email=<address>` showing the address and a (visually present, functionally disabled) resend control (AC-1.1.7).
- Duplicate-email / any registration failure renders as a **form-level** banner with the exact passthrough message from the API — never field-attributed, so it cannot disclose which field caused it (AC-1.1.2's non-disclosure applies at the UI layer too).
- No password value is ever logged anywhere in the Route Handler.
- The backend (`apps/api`, already merged on `main`) returns/expects camelCase JSON (ASP.NET Core minimal API default: `fullName`, `email`, `phone`, `password`, `passwordConfirmation` in the request; `{ email }` on 200 success; `{ detail, ... }` problem-details on 400; `{ message }` on 429 from a custom `OnRejected` handler — these are two *different* JSON shapes for the two error statuses, not one consistent error envelope. See Task 3 for the exact translation logic.
- **Env var naming correction from the spec:** the spec names the public Turnstile key `TURNSTILE_SITE_KEY`, but Next.js only inlines environment variables into the client bundle when they're prefixed `NEXT_PUBLIC_`. This plan uses `NEXT_PUBLIC_TURNSTILE_SITE_KEY` (client-safe) and `TURNSTILE_SECRET_KEY` (server-only, no prefix) — the secret key must never carry the `NEXT_PUBLIC_` prefix, or it would leak into the browser bundle.
- Local/dev default values (used when the env vars are unset): site key `1x00000000000000000000AA`, secret key `1x0000000000000000000000000000000AA` — these are Cloudflare's officially published "always passes" Turnstile test keys, safe to hardcode as fallbacks (they are not secrets; Cloudflare publishes them precisely for this purpose).
- Backend API base URL: read from `API_BASE_URL`, defaulting to `http://localhost:5176` (BE-1.1's local dev port, from `apps/api/MIM.Portal.Api/Properties/launchSettings.json`).
- **Framework caveat:** `apps/web/AGENTS.md` warns that this Next.js version may have breaking changes vs. training data and instructs reading `node_modules/next/dist/docs/` before writing code that touches unfamiliar APIs. `app/layout.tsx` already uses the newer `LayoutProps<"/">` typed-route pattern and Next 15+ requires `searchParams`/`params` in Server Component pages to be awaited `Promise`s, not plain objects — Task 5 (the check-email page) touches this directly. Consult the installed docs rather than assuming familiar Next.js APIs are unchanged.
- All new NuGet-equivalent (pnpm) packages are added via `pnpm add <name>` / `pnpm add -D <name>` with no manually-chosen version, letting pnpm resolve the version compatible with the installed Next.js/React/TypeScript versions.

`apps/web/lib/turnstile.ts`:

```ts
const SITEVERIFY_URL = "https://challenges.cloudflare.com/turnstile/v0/siteverify";
const DEFAULT_TEST_SECRET_KEY = "1x0000000000000000000000000000000AA";

export async function verifyTurnstileToken(
  token: string,
  remoteIp?: string,
): Promise<boolean> {
  const secretKey = process.env.TURNSTILE_SECRET_KEY ?? DEFAULT_TEST_SECRET_KEY;

  const body = new URLSearchParams();
  body.set("secret", secretKey);
  body.set("response", token);
  if (remoteIp) {
    body.set("remoteip", remoteIp);
  }

  const response = await fetch(SITEVERIFY_URL, {
    method: "POST",
    body,
  });

  const data = (await response.json()) as { success: boolean };
  return data.success === true;
}
```

- [ ] **Step 7: Implement the Route Handler**

`apps/web/app/api/register/route.ts`:

```ts
import { NextRequest, NextResponse } from "next/server";
import { verifyTurnstileToken } from "@/lib/turnstile";

const DEFAULT_API_BASE_URL = "http://localhost:5176";

interface RegisterRequestBody {
  fullName: string;
  email: string;
  phone: string;
  password: string;
  passwordConfirmation: string;
  turnstileToken: string;
}

export async function POST(request: NextRequest) {
  const body = (await request.json()) as RegisterRequestBody;
  const { turnstileToken, ...registerFields } = body;

  const remoteIp = request.headers.get("x-forwarded-for") ?? undefined;
  const captchaValid = await verifyTurnstileToken(turnstileToken, remoteIp);

  if (!captchaValid) {
    return NextResponse.json({ error: "captcha_failed" }, { status: 400 });
  }

  const apiBaseUrl = process.env.API_BASE_URL ?? DEFAULT_API_BASE_URL;

  const apiResponse = await fetch(`${apiBaseUrl}/identity/register`, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify(registerFields),
  });

  if (apiResponse.status === 200) {
    const data = (await apiResponse.json()) as { email: string };
    return NextResponse.json({ email: data.email }, { status: 200 });
  }

  if (apiResponse.status === 429) {
    const data = await apiResponse.json().catch(() => ({}) as { message?: string });
    return NextResponse.json(
      {
        error: "rate_limited",
        message: data.message ?? "Too many requests. Please try again later.",
      },
      { status: 429 },
    );
  }

  const data = await apiResponse.json().catch(() => ({}) as { detail?: string });
  return NextResponse.json(
    {
      error: "registration_failed",
      message:
        data.detail ??
        "We couldn't complete registration with these details. If you already have an account, try signing in or resetting your password.",
    },
    { status: 400 },
  );
}
```

```tsx
  FormLabel,
  FormMessage,
} from "@/components/ui/form";

const registerSchema = z
  .object({
    fullName: z.string().min(1, "Full name is required"),
    email: z.string().email("Enter a valid email address"),
    phone: z.string().min(1, "Phone number is required"),
    password: z.string().min(10, "Password must be at least 10 characters"),
    passwordConfirmation: z.string(),
    acceptedTerms: z.boolean().refine((value) => value === true, {
      message: "You must accept the Terms of Use and Privacy Notice",
    }),
  })
  .refine((data) => data.password === data.passwordConfirmation, {
    message: "Password and confirmation must match",
    path: ["passwordConfirmation"],
  });

type RegisterFormValues = z.infer<typeof registerSchema>;

const TURNSTILE_SITE_KEY =
  process.env.NEXT_PUBLIC_TURNSTILE_SITE_KEY ?? "1x00000000000000000000AA";

export function RegisterForm() {
  const router = useRouter();
  const [turnstileToken, setTurnstileToken] = useState<string | null>(null);
  const [formError, setFormError] = useState<string | null>(null);
  const [submitting, setSubmitting] = useState(false);

  const form = useForm<RegisterFormValues>({
    resolver: zodResolver(registerSchema),
    defaultValues: {
      fullName: "",
      email: "",
      phone: "",
      password: "",
      passwordConfirmation: "",
      acceptedTerms: false,
    },
  });

  async function onSubmit(values: RegisterFormValues) {
    if (!turnstileToken) {
      return;
    }

    setFormError(null);
    setSubmitting(true);

    try {
      const response = await fetch("/api/register", {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify({
          fullName: values.fullName,
          email: values.email,
          phone: values.phone,
          password: values.password,
          passwordConfirmation: values.passwordConfirmation,
          turnstileToken,
        }),
      });

      const data = await response.json();

      if (response.ok) {
        router.push(`/register/check-email?email=${encodeURIComponent(data.email)}`);
        return;
      }

      setFormError(data.message ?? "Something went wrong, please try again.");
    } catch {
      setFormError("Something went wrong, please try again.");
    } finally {
      setSubmitting(false);
    }
  }

  return (
    <Form {...form}>
      <form onSubmit={form.handleSubmit(onSubmit)} className="flex w-full max-w-md flex-col gap-4">
        {formError && (
          <div
            role="alert"
            className="rounded-md border border-destructive bg-destructive/10 p-3 text-sm text-destructive"
          >
            {formError}
          </div>
        )}

        <FormField
          control={form.control}
          name="fullName"
          render={({ field }) => (
            <FormItem>
              <FormLabel>Full name</FormLabel>
              <FormControl>
                <Input {...field} autoComplete="name" />
              </FormControl>
              <FormMessage />
            </FormItem>
          )}
        />

        <FormField
          control={form.control}
          name="email"
          render={({ field }) => (
            <FormItem>
              <FormLabel>Email</FormLabel>
              <FormControl>
                <Input {...field} type="email" autoComplete="email" />
              </FormControl>
              <FormMessage />
            </FormItem>
          )}
        />

        <FormField
          control={form.control}
          name="phone"
          render={({ field }) => (
            <FormItem>
              <FormLabel>Phone</FormLabel>
              <FormControl>
                <Input {...field} type="tel" autoComplete="tel" />
              </FormControl>
              <FormMessage />
            </FormItem>
          )}
        />

        <FormField
          control={form.control}
          name="password"
          render={({ field }) => (
            <FormItem>
              <FormLabel>Password</FormLabel>
              <FormControl>
                <Input {...field} type="password" autoComplete="new-password" />
              </FormControl>
              <FormMessage />
            </FormItem>
          )}
        />

        <FormField
          control={form.control}
          name="passwordConfirmation"
          render={({ field }) => (
            <FormItem>
              <FormLabel>Confirm password</FormLabel>
              <FormControl>
                <Input {...field} type="password" autoComplete="new-password" />
              </FormControl>
              <FormMessage />
            </FormItem>
          )}
        />

        <FormField
          control={form.control}
          name="acceptedTerms"
          render={({ field }) => (
            <FormItem className="flex flex-row items-start gap-2 space-y-0">
              <FormControl>
                <Checkbox checked={field.value} onCheckedChange={field.onChange} id="acceptedTerms" />
              </FormControl>
              <FormLabel htmlFor="acceptedTerms" className="font-normal">
                I accept the{" "}
                <a href="/terms" target="_blank" rel="noopener noreferrer" className="underline">
                  Terms of Use
                </a>{" "}
                and{" "}
                <a href="/privacy" target="_blank" rel="noopener noreferrer" className="underline">
                  Privacy Notice
                </a>
              </FormLabel>
              <FormMessage />
            </FormItem>
          )}
        />

        <Turnstile
          siteKey={TURNSTILE_SITE_KEY}
          onSuccess={(token) => setTurnstileToken(token)}
          onExpire={() => setTurnstileToken(null)}
        />

        <Button type="submit" disabled={!turnstileToken || submitting}>
          Create account
        </Button>
      </form>
    </Form>
  );
}
```
